# 用户用例与验收矩阵

## 用户故事

悬疑创作的困难是同一场景有多套知识：作者知道真相，人物给出证词，读者只看过部分线索。把所有材料交给Agent会让它用未揭示答案替读者推理。本插件持有证据结构和阶段投影，让推断严格基于当前可见材料。

作者说出目标，Codex发现能力、读取固定资料并准备成果；作者阅读与表达意见，下一轮保留旧依据。

## 测试分层

单元测试验证专业计算与反例，Schema测试验证闭合输入，CLI/MCP验证Core归属及事务，Electron验证真实阅读／播放和交互，当前Codex连接验证热发现和方法可读。正式安装包、源码构建、跨平台及创作品质分别记载，不互相替代。

联合旅程使用隔离原创样本，覆盖规则→悬疑读者视角→下一稿、美术参考→实际素材、固定录音→双语字幕→导出。原作摘要保持，外部发送和付费工具不自动触发。
