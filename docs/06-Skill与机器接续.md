# Skill与机器接续

## 接入方式

本包Skills随河图插件注册，外部Codex经同一稳定CLI/MCP即时发现`skills.read`，读取`hetu-mystery-lab`入口及按需参考。不向Codex安装同名插件，不增加永久客户端工具名，安装生命周期与作品管理连接分开。

## 默认旅程

读取固定原文与规划→登记命题、证词和线索→明确各阶段揭示→只用当时可见线索评估假说→对照作者真相查缺口→形成局部返工候选→沿新稿复核。

方法入口为[SKILL](../skills/hetu-mystery-lab/SKILL.md)，[操作地图](../skills/hetu-mystery-lab/references/operations.md)随清单生成，[流程](../skills/hetu-mystery-lab/references/workflows.md)描述专业决策。

## 有界发现与内容

先发现当前包摘要与专业Schema，再精确读取必要宿主动作。不全量加载所有插件方法，不用压缩摘要冒充已读原文。大成果使用summary与固定分块完整核验；只读投影不改变写入原输入。

## 恢复与用户决定

未知写入先查原键；同输入明确未落盘才恢复，不换键重复写入。CAS冲突保留输入。Agent执行准备与确定性事务，作者保留采纳、定稿、费用和外发决定。作者真相是专业设定候选，不自动成为宿主正典。confirmed仅表示本工程声明的线索可靠度；结构一致不证明诡计公平、读者一定猜出或现实案件结论。复用小说规划的时序与人物知情，不建立第二份正式时间线。
